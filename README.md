# Shop OS Egypt

نظام تشغيل رقمي بالذكاء الاصطناعي للمحلات المصرية الصغيرة والمتوسطة — بديل عن الـ POS التقليدي.

## الفكرة

محل واحد يسجل دخوله ويضيف منتجاته، فيشتغل له تلقائيًا:

`Inventory → Sales → Customers → Debts → WhatsApp → Online Store → AI Assistant`

كل ده من نفس قاعدة البيانات، وكل محل جديد ينضم يقوّي الشبكة لكل المحلات التانية (network effect).

## محتوى الريبو

| الملف / المجلد | الوصف |
|---|---|
| [`server/`](./server) | **Backend حقيقي** بـ Node.js + Express + SQLite: تسجيل دخول لكل محل، عزل بيانات كامل بين المحلات، مخزون، مبيعات، عملاء، ديون، ومساعد ذكي — تم اختباره فعليًا وشغال |
| [`app.html`](./app.html) | نسخة تجريبية أقدم (محلية في المتصفح بدون Backend) — احتفظنا بيها للمعاينة السريعة، لكن `server/` هي النسخة الحقيقية |
| [`PROMPT.md`](./PROMPT.md) | البرومبت الاحترافي الأصلي لتخطيط المشروع بالذكاء الاصطناعي |

## Backend — يخدم أكتر من محل في نفس الوقت

كل محل بيعمل حساب مستقل (تسجيل + كلمة سر)، وبياناته (المخزون، المبيعات، العملاء، الديون) معزولة تمامًا عن باقي المحلات في نفس قاعدة البيانات — تم اختبار العزل ده فعليًا بمحلين مختلفين.

### التقنيات المستخدمة
- **Node.js + Express** — الـ API
- **SQLite (better-sqlite3)** — قاعدة البيانات (ملف واحد، سهل النقل لاحقًا إلى PostgreSQL وقت التوسع)
- **JWT + bcrypt** — تسجيل الدخول وتشفير كلمات السر
- **Anthropic API** — المساعد الذكي، بيتغذى فعليًا من بيانات المحل الحقيقية (المخزون والديون والمبيعات) قبل ما يرد

### تشغيل السيرفر محليًا

```bash
cd server
npm install
cp .env.example .env
```

افتح `.env` وحط فيه:
```
JWT_SECRET=اكتب سلسلة عشوائية طويلة هنا
ANTHROPIC_API_KEY=مفتاحك من console.anthropic.com (اختياري، للمساعد الذكي فقط)
```

بعدين شغّل السيرفر:
```bash
npm start
```

افتح المتصفح على `http://localhost:3000` — هتلاقي شاشة "تسجيل دخول / حساب جديد"، اعمل حساب لمحلك وابدأ تستخدم التطبيق فعليًا.

### نشره أونلاين (رابط تقدر تبعته لحد يجربه)

أي استضافة بتدعم Node.js تصلح، زي Render أو Railway أو Fly.io:
1. ارفع مجلد `server` على GitHub (جزء من نفس الريبو ده).
2. اربط الريبو بالاستضافة، وحدد `npm start` كأمر تشغيل.
3. ضيف متغيرات البيئة `JWT_SECRET` و `ANTHROPIC_API_KEY` من لوحة تحكم الاستضافة نفسها (متبقاش تكتبهم في الكود).
4. الاستضافة هتديك رابط عام تقدر تبعته لأي حد يجرب التطبيق فعليًا.

### حدود النسخة الحالية (بصراحة)

- قاعدة البيانات SQLite ملف واحد على السيرفر — تكفي كويس لعشرات المحلات الأولى، لكن وقت التوسع الجدي المفروض تتنقل لـ PostgreSQL (نفس بنية الجداول تقريبًا).
- واتساب لسه Simulation (سجل إشعارات داخلي في لوحة التحكم) — مفيش إرسال رسائل فعلي، ده محتاج WhatsApp Business API منفصل.
- مفيش صفحة "استعادة كلمة السر" أو تفعيل بريد إلكتروني لسه.
- المساعد الذكي يحتاج مفتاح Anthropic API صالح في `.env` عشان يشتغل.

## الحالة الحالية

Backend حقيقي متعدد المحلات، مُختبر وشغال (register / login / عزل بيانات / بيع مع خصم مخزون / ديون / مساعد ذكي). جاهز للنشر أونلاين أو التطوير عليه أكتر.
